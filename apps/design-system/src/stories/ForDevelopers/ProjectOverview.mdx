### Project overview
This is a modern Nx monorepo designed for building scalable web applications with a comprehensive design system. The workspace is structured to support both application development and reusable component libraries.

#### Architecture overview
The project follows a monorepo architecture using Nx as the build system, with the following key characteristics:
- **Package Manager**: `pnpm` (for fast, efficient dependency management)
- **Build System**: `Nx` 20.8.1 (for intelligent caching and task orchestration)
- **Language**: `TypeScript` (for type safety and better developer experience)
- **Styling**: `Tailwind` CSS (for utility-first styling)
- **Testing**: `Jest` + `React Testing Library` (for unit testing)
- **E2E Testing**: `Playwright` (for end-to-end testing)
