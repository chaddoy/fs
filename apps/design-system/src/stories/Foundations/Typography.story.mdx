    ### Usage Guidelines

    #### When to use each size

    **Display sizes:**
    - **Display Large** - Hero sections, major page titles
    - **Display Medium** - Section headers, prominent announcements
    - **Display Small** - Page titles, important section headers

    **Heading sizes:**
    - **Heading 1** - Main page titles, primary content sections
    - **Heading 2** - Sub-sections, card titles
    - **Heading 3** - Content groups, form sections
    - **Heading 4** - Small sections, sidebar headers
    - **Heading 5** - Minor sections, table headers
    - **Heading 6** - Smallest headers, metadata labels

    **Body sizes:**
    - **Body Large** - Important content, lead paragraphs
    - **Body Medium** - Standard content, main text
    - **Body Small** - Secondary content, descriptions
    - **Body XSmall** - Captions, metadata, fine print

    #### Font weight guidelines

    **Light (300):**
    - Large display text
    - Decorative elements
    - Subtle emphasis

    **Regular (400):**
    - Body text
    - Standard content
    - Default weight

    **Medium (500):**
    - Subheadings
    - Important labels
    - Navigation items

    **SemiBold (600):**
    - Section headers
    - Button text
    - Strong emphasis

    **Bold (700):**
    - Page titles
    - Critical information
    - Maximum emphasis

    #### Line height guidelines

    **Tight (1.2-1.3):**
    - Display text
    - Headings
    - Short text blocks

    **Normal (1.4-1.5):**
    - Subheadings
    - Captions
    - Code snippets

    **Relaxed (1.6):**
    - Body text
    - Long-form content
    - Readable paragraphs

    ### Examples

    **Page structure:**
    ```tsx
    <div className="space-y-6">
      <h1 className="text-4xl font-bold">Page Title</h1>
      <p className="text-lg text-gray-600">Lead paragraph with important context.</p>
      
      <section>
        <h2 className="text-2xl font-semibold">Section Header</h2>
        <p className="text-base">Standard body text for the main content.</p>
        
        <h3 className="text-xl font-semibold">Subsection</h3>
        <p className="text-sm text-gray-600">Secondary content with smaller text.</p>
      </section>
    </div>
    ```

    **Card component:**
    ```tsx
    <div className="p-6 border rounded-lg">
      <h3 className="text-lg font-semibold mb-2">Card Title</h3>
      <p className="text-sm text-gray-600 mb-4">Card description text.</p>
      <button className="text-sm font-medium text-blue-600">Action</button>
    </div>
    ```

    **Form structure:**
    ```tsx
    <form className="space-y-4">
      <div>
        <label className="text-sm font-medium">Form Label</label>
        <input 
          type="text" 
          className="text-base font-mono"
          placeholder="Enter value"
        />
        <p className="text-xs text-gray-500">Helper text</p>
      </div>
    </form>
    ```
